Privacy Policy for Noio Chat

Last updated: June 5, 2026

1. Overview

Noio Chat is an offline communication application that enables one-to-one (1v1) messaging, voice calls, and file transfer using a direct device-to-device wireless connection.

This app works without internet, mobile data, or external servers.

2. Data Collection and Storage

  • The app does not collect or transmit personal data to external servers.
  • All communication happens directly between devices.
  • Chat history is stored locally on the user’s device only.

3. Data Sharing

No user data is shared with third parties. Communication is strictly peer-to-peer.

4. Permissions Used

  • Notifications
  • Microphone – for voice calls
  • Storage/Media – for file transfer
  • Nearby Wi-Fi / Wi-Fi Direct – for device connection
  • Location – for peer discovery

5. Internet Usage

This app does not require internet or cellular data for its core functions.

6. Security

Communication is encrypted during transmission. Security also depends on proper device usage and environment.

7. Children's Privacy

This app does not specifically target children under 13. No personal data is collected.

8. Changes

This policy may be updated in future versions of the app.

9. Contact

For questions, contact the developer through the app store listing support email.
